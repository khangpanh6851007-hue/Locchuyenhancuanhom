# 🛠️ Lộc Chuyên Hàn Cửa Nhôm

Website giới thiệu dịch vụ cơ khí, hàn xì cửa nhôm kính chuyên nghiệp, được thiết kế tối ưu giao diện di động (Mobile-first) với phong cách hiện đại phiên bản 5.0.

---

## 🌟 Tính Năng Nổi Bật

1. **Đồng Hồ Kỹ Thuật Số Thời Gian Thực:** Cập nhật giờ, phút, giây liên tục theo thời gian thực.
2. **Lịch Biểu Tự Động:** Tự động hiển thị chính xác Thứ, Ngày, Tháng, Năm hiện tại.
3. **Giao Diện 5.0 (Glassmorphism):** Hiệu ứng kính mờ sang trọng, tối ưu trải nghiệm mượt mà trên mọi thiết bị di động (tương thích hoàn hảo với **Acode** & **Trebedit**).
4. **Tích Hợp Google Maps:** Bản đồ trực quan giúp khách hàng dễ dàng tìm đường đến xưởng.
5. **Tương Tác Nhanh (Call-to-Action):** Nút gọi điện nhanh hotline và liên kết chỉ đường trực tiếp chỉ với một chạm.

## 📍 Thông Tin Liên Hệ & Địa Chỉ

* **Cơ sở:** Ấp Tân An, Xã Tân Thành Bình, Tỉnh Vĩnh Long.
* **Google Maps:** [Xem bản đồ chỉ đường](https://maps.app.goo.gl/jWmD2My518UjSZpcA)

## 💻 Công Nghệ Sử Dụng

* **HTML5 / CSS3** (Giao diện hiện đại, tối ưu responsive).
* **JavaScript (ES6+)** (Xử lý đồng hồ và lịch tự động theo thời gian thực).
* **Font Awesome 6** (Bộ icon hiện đại).
* **Google Fonts (Poppins)** (Phông chữ tiêu chuẩn quốc tế).

---

## 🚀 Hướng Dẫn Cài Đặt & Sử Dụng

Bạn có thể chạy dự án này trực tiếp trên điện thoại thông qua ứng dụng **Acode** hoặc **Trebedit**:

1. Tải hoặc sao chép mã nguồn file `index.html` vào bộ nhớ ứng dụng.
2. Mở file bằng trình duyệt tích hợp hoặc xem trước (Preview) trực tiếp trên Acode/Trebedit.
3. (Tùy chọn) Đẩy mã nguồn này lên kho lưu trữ GitHub của bạn để làm trang web giới thiệu dịch vụ cá nhân.
